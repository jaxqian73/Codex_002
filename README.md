# Jaqtrax Invest

面向美股投资新手的中文学习与模拟分析 Web App。使用 React、TypeScript、Vite、Recharts 和普通 CSS，便于逐步学习和维护。

> **Demo Data：所有行情、价格、涨跌幅、市值和曲线均为虚构演示数据，并非实时或历史行情。仅供学习，不构成投资建议。** 不使用真实资金，不连接券商，不提供自动交易。无登录、数据库或付费 API。

## 如何预览

需要 Node.js 22 或以上版本及 npm。在终端运行：

```bash
cd /workspace/--
npm ci --cache /workspace/.npm-cache
npm run dev
```

终端会显示开发服务器地址，默认端口为 **5173**。在支持端口转发的开发工具中打开该端口；如果在自己的电脑运行，可直接打开终端显示的本机地址。服务器只用于开发，项目尚未公开部署。公开部署前需得到项目所有者确认。

其他命令：

```bash
npm test          # 运行自动化测试
npm run build    # TypeScript 检查并生成 dist/ 静态文件
npm run preview  # 本地检查构建结果，默认端口 4173
```

## 如何使用

- **市场概览**：点击三大指数卡片切换市场走势图，或在走势图右上角选择股票 / ETF；区间按钮切换演示曲线。曲线是公式生成的示意采样点，不代表对应时间的真实交易记录。
- **我的自选**：默认包含 AAPL、MSFT、NVDA、GOOGL、VOO、QQQM、VT。按股票代码或英文名称搜索；点击“添加自选”选择演示资产；垃圾桶按钮删除。V1 仅支持内置的十项资产。
- **投资组合**：点击“添加持仓”，选择代码，填写数量和买入单价（USD），保存后自动汇总。允许小数股，同一资产可分多笔记录。删除无法撤销，修改可通过删除后重新添加完成。
- **投资学院**：阅读股票、ETF、P/E、EPS、Free Cash Flow、复利和风险管理卡片，点击卡片展开中文说明。
- **复利计算器**：调整初始本金、每月投入、整数年限和预期年化收益率，查看期末资产和累计投入。允许负收益率；模拟结果不代表实际收益，可能亏损。
- **深浅色模式**：点击右上角太阳 / 月亮按钮切换。

## 计算规则

持仓成本 = 数量 × 买入单价；模拟市值 = 数量 × 内置模拟价格；盈亏 = 市值 − 成本；收益率 = 盈亏 ÷ 成本。金额以美元显示，不计股息、税费、交易费或汇率。ETF 的市值栏显示“不适用”，避免把基金规模与公司市值混用。

复利以年化假设收益率除以 12 作为月利率，每月先计收益、再于月末投入。年末记录图表数据。不考虑税费、通胀或市场波动；这只是数学情景分析。

## 数据保存与隐私

主题、自选股、持仓保存在当前浏览器的 `localStorage`，刷新后保留；不会发送到服务器，不跨设备同步。清除浏览器网站数据会删除记录，请勿将这里作为唯一的投资账本。禁用存储或容量不足时，界面会提示更改仅在当前页面有效。损坏的数据会安全回退到默认值。

使用的键：`jaqtrax.theme`、`jaqtrax.watchlist`、`jaqtrax.holdings`。

## 如何修改

| 文件 | 用途 |
| --- | --- |
| `src/App.tsx` | 页面、导航和交互 |
| `src/style.css` | 布局、颜色、响应式和深浅色主题 |
| `src/finance.ts` | 演示资产、学习内容和计算函数 |
| `src/storage.ts` | 浏览器本地存储 |
| `src/finance.test.ts` | 持仓和复利公式测试 |
| `src/App.test.tsx` | 添加、删除、搜索、持久化和交互测试 |

修改颜色：在 `src/style.css` 中搜索 `.app`，调整 `--bg`（背景）、`--panel`（卡片）、`--green`（强调色）等变量。修改模拟价格或课程：编辑 `src/finance.ts`。Vite 会在保存后自动刷新开发页面。

依赖版本由 `package-lock.json` 锁定。日常恢复依赖请使用 `npm ci`，避免无意升级。界面不依赖外部字体或行情接口。

## V1 范围

桌面优先，兼容手机；没有用户系统、云备份、实时价格或交易能力。后续接入真实行情时，需要独立设计数据授权、延迟标识和错误处理，不能直接移除 Demo Data 标识。当前测试为浏览器模拟环境交互测试和计算单元测试，不能替代真实设备验收。
